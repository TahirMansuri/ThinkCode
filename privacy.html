Privacy Disclosure

Privacy Policy for ThinkCode

Application: ThinkCode Package: com.igc.thinkcode Last Updated: October 2026

1. Introduction

Welcome to ThinkCode ("we", "our", or "us"). We are committed to protecting your privacy. This Privacy Policy explains how information is handled when you use the ThinkCode mobile application and web visualization platform.

ThinkCode is an interactive educational platform designed for computer science students, educators, and software engineers to visualize data structures, simulate algorithms, and trace C++ execution.

Key Summary: ThinkCode operates primarily as a client-side offline educational tool. We do not collect, store, sell, or transmit any Personally Identifiable Information (PII) to external servers.

2. Information We Collect

We respect your privacy and minimize data handling strictly to essential local device functionality:

  • No Personal Identification Data: We do not ask for or collect your name, email address, phone number, physical address, biometric data, or government IDs.
  • No Sensitive Permissions: ThinkCode does not request access to your device camera, microphone, contacts, SMS, photos, or physical GPS location.
  • Local State & Preferences: User settings (such as dark/light/midnight theme selection, custom algorithm code inputs, visualizer playback speeds, and practicals bookmarks) are stored strictly on your local device storage using standard browser/WebView sandboxed local storage (localStorage). This data never leaves your device.

3. Internet Access & Network Usage

ThinkCode requests standard internet access permission solely for loading core web assets (such as web font definitions, external syntax libraries, and web-based documentation links) and verifying remote webview assets. No user telemetry, analytics, profiling, or behavioral tracking data is sent across the network.

4. Third-Party Services

The application is built using the open-source Capacitor framework and distributed through the Google Play Store. These platforms may process non-identifiable technical data as part of standard operating system operations:

  • Google Play Services: Used by your Android device for secure application installation, update delivery, and standard anonymized operating system crash reports (subject to Google's Privacy Policy).
  • GitHub Pages: Used to host official public documentation and web visualization mirrors (subject to GitHub's Privacy Statement).

5. Children's Privacy (COPPA & GDPR-K Compliance)

ThinkCode is an educational utility suitable for students and learners of all ages. Because ThinkCode does not collect, retain, or share any personal information whatsoever, it fully complies with the United States Children's Online Privacy Protection Act (COPPA) and international child privacy regulations.

If a parent or guardian believes that any personal information has inadvertently been provided, please contact us immediately, and we will ensure no such data exists or is retained.

6. Data Retention & Deletion

Because all configuration and code traces are saved purely in local sandboxed storage on your device:

  • You can erase all stored data at any time by clearing the app data in Android Settings > Apps > ThinkCode > Storage > Clear Storage.
  • Uninstalling the ThinkCode application immediately removes all locally cached files and preferences from your device.

7. Security Practices

We prioritize the security of our users. Because all algorithm emulations and code execution parsing run locally within your device's isolated runtime sandbox, your custom code and inputs are protected against unauthorized network interception.

8. Changes to This Privacy Policy

We may update our Privacy Policy periodically to reflect technological improvements or regulatory updates. Any changes will be published directly to this page with an updated "Last Updated" date.
